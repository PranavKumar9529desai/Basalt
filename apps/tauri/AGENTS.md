## Commands

Run from `apps/tauri/` unless noted:

```bash
bun run dev               # Vite dev server (frontend only, no Tauri window)
bunx tsc --noEmit         # TypeScript type-check
bun run test              # Vitest unit tests
bun run build             # tsc + vite production build
```

From the **repo root**:

```bash
bun run dev               # full Tauri dev server + window
bun run lint              # Oxlint
cargo test --workspace    # Rust unit tests (src-tauri + crates)
cargo build               # Rust build
bun run build:wasm        # regenerate graph_sim.wasm + frontmatter WASM (after Rust crate changes)
```

Always run `bun run lint && bunx tsc --noEmit` after completing an
implementation step, and `cargo test --workspace` for any Rust change.

## Architecture (app layer)

Dependencies flow downward only. See `../../AGENTS.md` and `../../CONVENTIONS.md`
for the full rules.

```
routes/       TanStack Router — exactly 2 modes ("/" + "/onboarding"), never more
app-shell/    Thin layout composition; the ONLY place cross-feature wiring renders
shared/       Cross-feature orchestration; the ONLY place to import 2+ features
features/     Business logic, one directory per domain — zero cross-feature imports
src-tauri/    Rust backend: lib.rs + commands/* (all IPC), watcher, config, cache
```

Two rules that trip up most contributors:

- **Features never import each other** — `features/{vault,tabs,editor,search,
settings,graph}` have no imports between them. Cross-feature wiring lives in
  `shared/` or `app-shell/`. The one exception is type-only imports via a
  feature's `types.ts`.
- **The shell renders from registries, not hardcoded imports** — new panels and
  leaves register in `app-shell/registrations.ts` (ADR-018). Never edit
  `SideDock.tsx` or the tab renderers to add a view.

Each feature has an `index.ts` barrel — the only legal import surface for other
layers. Depth: `./README.md#2-directory-map`.

## Boundaries

**Always**

- Register new views/leaves (docks, tab types, graph leaf) in
  `app-shell/registrations.ts`; that single registration is the wiring step.
- Register commands/actions **once** at boot (side-effect imports in `shared/`),
  resolving the active editor at execution time via `editorControllerRegistry`
  + `tabsStore.activePaneId`. Never register per-pane — the CommandService
  "already registered. Overwriting." warning is the dev guard against it.
- Put anything needing 2+ features in `shared/`.
- Batch related `invoke(...)` calls into one (`save_files`/`open_files` exist).
- Virtualize lists over ~100 items (`@tanstack/react-virtual`).
- Use `--sat-*` theme tokens for all colors; Tailwind only for layout/spacing.

**Ask first**

- Adding a new Tauri command (touches `src-tauri/src/lib.rs` + a feature hook).
- Changes to the write contract in `src-tauri/src/commands/files.rs`
  (self-write markers → cache → search index → emit nothing).
- Changing tab persistence format `features/tabs/store/persistence.ts` (v1
  snapshot, structural-change-only persistence key).

**Never**

- ✗ Import one feature from another (type-only via `types.ts` allowed).
- ✗ Add per-keystroke React re-renders in the editor — typing path is
  React-free; CM6 swaps state via `view.setState()` on `Host.tsx`.
- ✗ Edit `routeTree.gen.ts` (generated by TanStack Router).
- ✗ Add a route for something that should be a tab or panel (graph, settings,
  backlinks are all leaves/docks, not routes).
- ✗ Store note _content_ in React state — `useActiveNoteStore` holds stats only.
- ✗ Banner/box comments or bare ADR name-drops (CONVENTIONS §8).

## Key seams / where things are

| Area                            | Read first                                                                                   |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| Add a sidebar dock / tab leaf   | `app-shell/registrations.ts` + `packages/views`                                              |
| Wire two features together      | `shared/` (never inside a feature)                                                           |
| Note open → editor → save       | `shared/useWorkspace.ts` → `useEditor` → `logic/saveManager`                                 |
| Editor typing path              | `packages/editor` (CM6 extensions) — keep it React-free                                      |
| Add / trace IPC commands        | `src-tauri/src/lib.rs` + `src-tauri/src/commands/*`                                          |
| Boot flow / TTI                 | `app-shell/Boot.tsx`, `routes/index.tsx`, `src-tauri/src/commands/boot.rs`                   |
| Frontend↔backend event contract | `vault://file-changed` (external changes only); reconcile via `features/editor/reconcile.ts` |

Depth for boot, state, seams, and the registry spine:
[`./README.md`](./README.md#5-frontend--backend-rust-seams).
